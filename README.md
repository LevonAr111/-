# Порт-Мираж — своя версия с сервером

В папке три файла:

- `index.html` — сама игра;
- `server.js` — сервер: раздаёт игру и связывает игроков между собой;
- `package.json` — описание проекта для хостинга.

Серверу нужен только Node.js 18 или новее, ничего устанавливать через npm не надо.

## Вариант 1. Запустить на своём компьютере

1. Установите Node.js с https://nodejs.org (версия LTS).
2. Откройте терминал в этой папке и выполните: `node server.js`
3. Откройте в браузере http://localhost:3000 — это игра.

Друзья в той же сети (тот же Wi-Fi) заходят по адресу `http://ВАШ_IP:3000`,
где ВАШ_IP — локальный адрес компьютера (например, 192.168.1.5).
Друзьям из интернета этот адрес недоступен: для них нужен хостинг (вариант 2)
или проброс порта 3000 на роутере.

## Вариант 2. Выложить на хостинг

Подойдёт любой хостинг, который запускает Node.js как постоянно работающий
веб-сервис с поддержкой WebSocket. Хостинги только для статических сайтов и
«функций» (GitHub Pages, Vercel, Netlify) не подойдут: там игра откроется,
но игроки друг друга не увидят.

Общий порядок (на примере Render, у других похоже):

1. Создайте репозиторий на GitHub и загрузите в него эти три файла.
2. На хостинге создайте новый Web Service и подключите репозиторий.
3. Команда сборки (build): оставьте пустой или `npm install`.
   Команда запуска (start): `node server.js`.
4. После развёртывания хостинг выдаст адрес вида `https://ваше-имя.onrender.com` —
   это и есть ссылка для друзей.

Порт сервер берёт из переменной окружения `PORT`, которую задаёт хостинг.

На бесплатных тарифах сервис обычно «засыпает» без посетителей и просыпается
около минуты при первом заходе — это нормально. Если соединение рвётся, игра
сама переподключается через несколько секунд.

## Отдельные комнаты

Все, кто открыл одну и ту же ссылку, попадают в один город. Чтобы играть
отдельной компанией, добавьте к адресу `?room=любое-слово`, например
`https://ваш-адрес/?room=druzya` — друг друга увидят только те, у кого
совпадает это слово.

## Проверка

`https://ваш-адрес/health` показывает, что сервер работает, и число игроков.
